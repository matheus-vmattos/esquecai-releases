# Página do beta do EsquecAI

Página estática para os testadores baixarem o instalador sem passar pelo GitHub.

- Hospedagem: Cloudflare Pages (plano grátis), ligado a este repositório, com a pasta de saída `site` e sem comando de build.
- O botão "Baixar" aponta para `releases/latest/download/EsquecAI-Setup.exe`, a cópia com nome fixo que cada publicação sobe junto com o instalador versionado.
